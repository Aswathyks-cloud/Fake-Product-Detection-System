# Fake Product Detection System

## 📌 Description
A blockchain-based system to detect fake products using RFID.

## 🚀 Features
- Manufacturer product registration
- Consumer product verification
- Blockchain-based storage
- PDF report generation

## 🛠 Technologies Used
- Python
- Streamlit
- MySQL
- Blockchain
- FPDF

## ▶️ How to Run
1. Install requirements
2. Run: streamlit run streamlit_app.py
